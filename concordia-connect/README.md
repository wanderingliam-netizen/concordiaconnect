# ConcordiaConnect — functional HTML prototype

A self-contained front-end prototype inspired by the supplied ConcordiaConnect visual reference.

## Included
- Dark + white app UI with Concordia-magenta accents.
- Post Board with seeded test posts, category filters, search, likes, comments, shares, post creation and post detail modal.
- Friend Finder with pass / save / like interactions and instant match creation.
- Matches screen with selectable match list and working demo chat (messages persist in localStorage).
- Newsletter with 3 complete sample issues and article detail modals.
- Profile editor with local persistence.
- Responsive mobile bottom navigation.
- All demo data persists in your browser via `localStorage`.

## Run
Open `index.html` in a browser. For the smoothest experience, serve the folder with a tiny local server (for example `python3 -m http.server` from this folder).

## Notes
This prototype intentionally uses local SVG artwork rather than external stock-photo dependencies so the ZIP works offline. The supplied design reference is included as `assets/design-reference.png`.
